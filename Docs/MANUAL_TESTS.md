# 수동 테스트 및 App Store 점검

아래 항목은 **아직 실기기에서 실행되지 않았습니다**. 테스트할 때 기기·iOS·Xcode 버전과 결과를 기록하고 실제 개인정보는 사용하지 마세요. 이 문서의 합성 예문을 사용합니다.

## 설치 및 기본 흐름

- [ ] Mac에서 `swift test`, 앱/확장 빌드, XCTest/UI 테스트 모두 성공
- [ ] 실제 식별자·개발자 팀·App Group·Keychain 그룹 설정 후 iPhone 설치
- [ ] 메인 앱의 안내에 따라 키보드 추가
- [ ] 전체 접근 OFF 상태에서 메모 앱의 지구본으로 전환
- [ ] `ㅇㅏㄴㄴㅕㅇㅎㅏㅅㅔㅇㅛ` 입력 → `안녕하세요`
- [ ] Mock에서 `こんにちは` 후보 → 탭 → 원문 5글자만 교체
- [ ] 같은 후보를 빠르게 두 번 눌러도 원문을 두 번 삭제하지 않음
- [ ] 한/영 전환, Shift/쌍자음, 숫자·기호, 공백, 엔터, 숨기기, 지구본 길게 누르기
- [ ] `ㄷㅏㄹㄱㅏ` → `달가`; 삭제 → `닭` → `달` → `다` → `ㄷ` → 빈칸

## 입력 문맥과 교체

- [ ] `hello  ` → 번역 후 뒤 공백 보존
- [ ] 이전 문장이 있는 입력창에서 새로 입력한 마지막 문장만 대상
- [ ] 커서를 옮기거나 입력창을 전환하면 기존 후보 무효화
- [ ] 선택 영역이 있을 때 후보가 선택 문장을 덮어쓰지 않음
- [ ] `é`, 가족 이모지, 국기, 분해 한글을 포함한 원문에서 삭제 없이 삽입 전용 표시
- [ ] 호스트 자동 수정 또는 긴 문맥 이동으로 교체가 중단되면 추가 삭제하지 않음
- [ ] 긴 문서가 열린 것만으로 네트워크 요청이 발생하지 않음
- [ ] 엔터 이후 이전 줄 후보가 적용되지 않음

## 권한·네트워크·생명주기

- [ ] 전체 접근 OFF에서도 한국어·영어 기본 입력 유지
- [ ] 원격 서비스에서 전송 동의 OFF이면 요청하지 않음
- [ ] 전체 접근 OFF이면 원격 요청하지 않고 안내
- [ ] 실제 HTTPS 서버·토큰 설정 후 일반 한국어 문장이 일본어로 번역됨
- [ ] 401, 429, 오프라인, 타임아웃 상황에서 오류 표시와 재시도
- [ ] 실패/번역 중에도 키 입력이 지연되거나 소실되지 않음
- [ ] Wi-Fi 전용 ON + 셀룰러에서는 요청하지 않음
- [ ] 번역 OFF 또는 키보드 닫기 시 요청 취소, 늦은 응답 미표시
- [ ] 빠르게 문장을 바꿀 때 최신 결과만 표시
- [ ] 키보드 재실행 시 이전 원문·후보가 남지 않음
- [ ] 비밀번호·전화번호 필드에서 시스템 키보드로 전환
- [ ] Safari, 메시지, 메일, 메모, TestHost 각각 같은 흐름 확인

## 접근성·성능·개인정보

- [ ] 라이트/다크/시스템 설정 전환 시 앱·키보드 반영
- [ ] 가장 작은 iPhone 세로 화면에서 잘림·터치 충돌 없음
- [ ] Dynamic Type 일반/접근성 크기에서 후보와 키가 사용 가능
- [ ] VoiceOver가 목표 언어·실제 번역문·교체/삽입 동작을 읽음
- [ ] VoiceOver로 한글 입력과 후보 적용 가능
- [ ] Instruments에서 연속 입력·번역·재실행 후 메모리가 지속 증가하지 않음
- [ ] 운영 로그, Crash 수집, App Group, UserDefaults, 네트워크 캐시에 원문/번역문 없음
- [ ] 서버·리버스 프록시·APM에 요청/응답 본문과 인증 헤더가 기록되지 않음

## 출시 차단 항목

- [ ] 앱/확장 Archive·서명·실기기 테스트 완료
- [ ] 실제 Bundle ID 및 App Group/Keychain entitlement 일치
- [ ] 배포용 App Icon, 스크린샷, 설명, 연락처 준비
- [ ] 개발용 서비스 표시/제공 여부를 출시 정책에 맞게 결정
- [ ] 개인 서버 파일럿을 공개 서비스로 운영하려면 사용자 인증·토큰 발급/회수·계정별 제한 구현
- [ ] 실제 제공자·호스팅 정책을 반영한 공개 개인정보 처리방침·이용약관·문의 URL
- [ ] 개인정보 매니페스트와 App Store 개인정보 질문 재검토
- [ ] 전체 접근 이유, 전송 범위, 보관 여부를 심사 설명에 기재
- [ ] 번역 API 플랜·비용·이용 조건·데이터 보관/이전 검토
- [ ] 사용자에게 키보드 제거·앱 삭제 경로 안내

기본 서드파티 키보드 제한, 키보드 승인 설정, 시스템 앱 간 동작은 UI 테스트 2개로 검증되지 않습니다. 수동 검사를 별도로 완료해야 합니다.
